Framework

WAT Architecture — Workflows · Agents · Tools

📋
Layer 1: Workflows

Markdown SOPs in workflows/. Define objectives, inputs, tool sequence, outputs, and edge-case handling in plain language.

  • add_new_ticker.md
  • morning_session.md
  • risk_review.md
  • backtest.md
🤖
Layer 2: Agents (Claude Code)

Intelligent orchestration. Reads workflows, runs tools in correct sequence, handles failures gracefully, updates workflows on new learnings.

  • Reads the relevant workflow SOP
  • Sequences tool calls deterministically
  • Retries → fallback → log on failure
  • Self-improves via documented learnings
⚙️
Layer 3: Tools

Python scripts in tools/ that execute deterministically. API calls, data transforms, file I/O. Credentials live only in .env.

  • market_data.py — Finnhub + yfinance
  • session_manager.py — portfolio state
  • telegram_bot.py — notifications
  • sector_analysis.py — momentum
Core Engine

Multi-Agent Trading Pipeline — 7 Agents, 1 Decision

Runs every morning for each eligible ticker in the watchlist. Each agent receives the full state from all previous agents and appends its analysis before passing forward.

Pre-Filter (before any LLM call) Earnings blackout window Same-sector cap (max 1 per sector) Volume ≥ 80% of 20d avg Circuit breaker check Max 3 concurrent positions Portfolio heat > 85% → skip VIX > 35 → no trades

LLM Strategy

Model Routing — Multi-LLM via LiteLLM (~$0.60/day)

Agent Model Provider Why This Model Est. Cost
Fundamental Analyst llama-3.1-70b-versatile Groq Structured output formatting; fast inference; 5× cheaper than Haiku ~free
Sentiment Analyst llama-3.1-70b-versatile Groq High throughput for Reddit/news text classification at zero marginal cost ~free
Technical Analyst llama-3.1-70b-versatile Groq Pattern recognition from indicator values; no premium quality needed ~free
Bull Researcher gpt-4o-mini OpenAI Logical argumentation and rebuttal quality; better debate than Llama at low cost ~$0.01/day
Bear Researcher gpt-4o-mini OpenAI Symmetric debate partner for the bull; same model ensures fair argumentation quality ~$0.01/day
Trader claude-sonnet-4-6 Anthropic Best synthesis/cost balance; reads full report chain, proposes sized position with rationale ~$0.10/day
Risk Manager llama-3.1-70b-versatile Groq Rule-based validation maps well to structured JSON output; no premium model needed ~free
Fund Manager claude-opus-4-6 Anthropic ⚡ Non-negotiable. Highest-stakes final gate. Best contextual reasoning for nuanced capital allocation decisions. ~$0.47/day

All agents use litellm.completion() — unified interface, identical semantics across providers. Cost reduced from ~$5.00/day to ~$0.60/day (88% reduction).
